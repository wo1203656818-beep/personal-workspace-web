# 新功能脑暴

基于现有数据模型和功能，以下是可新增的实用功能建议。

---

## 候选功能列表

### 1. 每周/月 AI 总结报告 ⭐⭐⭐⭐⭐

**价值**: 将分散在多个模块的数据聚合为一份智能报告，帮助用户回顾和复盘。

**数据来源**（全部已存在）:
| 数据 | 表 |
|------|-----|
| 任务完成情况 | `tasks` |
| 专注时长 | `focus_sessions` |
| 习惯打卡 | `habit_checkins` |
| 日记条目数 | `journal_entries` |
| 情绪日志 | `mood_logs` |
| 目标进度 | `goals` |

**实现方式**:
- 后端: `GET /api/ai/review?period=weekly|monthly` — 读取指定周期数据，构建 prompt 调用 AI
- KV 缓存结果（TTL 1 小时，避免重复调用）
- 前端: 首页新增"AI 总结"卡片，或独立页面
- 支持手动刷新和自动生成

**复杂度**: 中（后端 API + 前端卡片）

---

### 2. 任务看板视图 ⭐⭐⭐⭐

**价值**: 任务已有 `status` 字段（planned/committed/in_progress/done），看板视图让任务管理更直观。

**数据来源**:
| 数据 | 表 | 字段 |
|------|-----|------|
| 任务状态 | `tasks` | `status` |

**实现方式**:
- 前端: TasksPage 新增"看板"标签页，四列展示
- 拖拽切换状态（使用 @dnd-kit）
- 现有 TasksPage 已使用 @dnd-kit（拖拽排序），可复用

**复杂度**: 低（仅前端，无后端改动）

---

### 3. 专注年度热力图 ⭐⭐⭐⭐

**价值**: GitHub 风格热力图直观展示全年专注记录，激励持续专注。

**数据来源**:
| 数据 | 表 | 字段 |
|------|-----|------|
| 专注会话 | `focus_sessions` | `startedAt`, `completed`, `minutes` |

**实现方式**:
- 后端: `GET /api/focus/heatmap?year=2026` — 按天聚合专注时长
- 前端: FocusPage 添加"年度热力图"标签页
- 复用 `react-activity-calendar`（HabitsPage 已使用）
- 点击日期查看当天专注详情

**复杂度**: 低（后端简单聚合 + 前端复用组件）

---

### 4. AI 支出分析 ⭐⭐⭐⭐

**价值**: 对记账数据进行 AI 深度分析，发现消费模式和优化空间。

**数据来源**:
| 数据 | 表 | 字段 |
|------|-----|------|
| 记账流水 | `expenses` | `amount`, `category`, `date`, `note` |

**实现方式**:
- 后端: `GET /api/records/ai-analysis` — 读取最近 N 天支出，调用 AI 分析
- 分析维度: 月度趋势、分类占比、异常支出、省钱建议
- KV 缓存 1 小时
- 前端: RecordsPage 新增"AI 分析"标签页

**复杂度**: 中（后端 API + 前端标签页）

---

### 5. 日记 AI 智能提示 ⭐⭐⭐

**价值**: 写日记时 AI 根据当天情况提供个性化写作提示，降低写作门槛。

**数据来源**:
| 数据 | 表 |
|------|-----|
| 今日任务完成 | `tasks` |
| 今日专注 | `focus_sessions` |
| 今日习惯 | `habit_checkins` |
| 昨日日记 | `journal_entries` |
| 今日情绪 | `mood_logs` |

**实现方式**:
- 后端: `GET /api/journal/prompts` — 读取当天相关数据，AI 生成 3 条写作提示
- 前端: JournalPage 编辑区上方显示提示卡片
- 用户可点击提示快速填充内容

**复杂度**: 低（后端简单 API + 前端小改动）

---

### 6. 快捷面板（全局命令增强）⭐⭐⭐

**价值**: 增强现有的 Command Palette，支持快速查看摘要、创建内容、跳转。

**实现方式**:
- 扩展 CommandPaletteDialog 功能
- 支持: 快速查看今日摘要、创建任务/笔记/日记、搜索全部内容
- 无需后端改动

**复杂度**: 低（仅前端）

---

## 推荐优先级

按价值/复杂度比排序:

| 优先级 | 功能 | 价值 | 复杂度 | 建议 |
|--------|------|------|--------|------|
| P0 | 每周/月 AI 总结报告 | ⭐⭐⭐⭐⭐ | 中 | 独立页面，首页留入口 |
| P1 | 任务看板视图 | ⭐⭐⭐⭐ | 低 | TasksPage 新增标签页 |
| P1 | 专注年度热力图 | ⭐⭐⭐⭐ | 低 | FocusPage 新增标签页 |
| P2 | AI 支出分析 | ⭐⭐⭐⭐ | 中 | RecordsPage 新增标签页 |
| P2 | 日记 AI 智能提示 | ⭐⭐⭐ | 低 | JournalPage 小改动 |
| P3 | 快捷面板增强 | ⭐⭐⭐ | 低 | CommandPalette 增强 |

---

## 不变项

- 不新增数据库表（全部使用现有数据）
- 不修改现有 API 的返回格式
- 不修改现有路由结构
- 不新增 npm 依赖（除非必要）
